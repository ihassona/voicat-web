Description of Service

VoiCat Private is an iOS application that enables users to:

  • Record and import audio files
  • Transcribe audio to text using Apple's on-device Speech framework
  • Translate transcriptions using Apple's on-device Translation framework
  • Generate summaries of audio content using Apple Intelligence, where supported by the device

All core AI features run entirely on your device and do not require an internet connection. An internet connection is only used for showing ads, anonymous app analytics, optional push notifications, and processing an in-app purchase.

Summarization requires an Apple Intelligence–compatible device and iOS version. On an unsupported device, summarization is unavailable; transcription and translation are unaffected.
